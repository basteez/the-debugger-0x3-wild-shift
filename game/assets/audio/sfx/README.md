# SFX (Story 7.2)

Every file in this folder is generated by `game/tools/gen_sfx.py` (Python standard library only,
deterministic: no RNG, fixed-seed LFSR noise). The sounds are synthesised by this project's own
code, so they are **CC0 by construction**. Format: 16-bit mono PCM WAV, 22050 Hz, peak at most
0.8 of full scale, fade-out at the end. Godot imports them with compression **Disabled** (keep it:
the asset test reads the 16-bit samples) and no loop.

Status: **final** for the jam (pending Tiziano's listening pass, H-S72-2). To change a sound, edit
its recipe in `gen_sfx.py` and rerun `python3 game/tools/gen_sfx.py`; never edit a WAV by hand. The
file names are fixed: a replacement is a file swap, not a code change.

Determinism check (not run by CI):

```sh
python3 game/tools/gen_sfx.py --out /tmp/sfx
for f in game/assets/audio/sfx/*.wav; do cmp "$f" "/tmp/sfx/$(basename "$f")"; done
```

No output means the committed files match the generator.
