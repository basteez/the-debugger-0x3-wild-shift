# Music (Story 7.1)

All eight files in this folder are **PLACEHOLDERS**. They are generated by
`game/tools/generate_placeholder_music.py` (deterministic, no RNG; needs `numpy` and `soundfile`
in a throwaway virtual env, see the script header). They only exist so the music plumbing
(`AudioManager.crossfade_to`, phase-3 glitch, Breakpoint muffled loop) can be built, tested and
heard before the real tracks exist.

HARVEST is silent (the music fades out over 30 frames).

## Placeholder format

Ogg Vorbis, mono, 22050 Hz, 120 BPM, 4 bars of 4/4 = exactly 8.0 s, imported with `loop=true`.
Generated by this project's own code: CC0.

## Replacing a placeholder with a real track

**Hard constraint: every one of the eight files must have exactly the same length (same BPM and
bar count).** The glitch and muffled variants start at the playback position of the track they
replace, so a track of a different length drifts off the bar. The unit test
`test_variants_share_the_length_of_their_family` fails CI otherwise. Today all eight are 8.0 s.

1. Export the BeepBox track as `.ogg` (or WAV, then convert to Ogg Vorbis) with the **same file
   name**. Overwrite the placeholder; keep the existing `.ogg.import` file.
2. A base track and its `_glitch` variant must have the **same length, BPM and bar count**, and
   `breakpoint_muffled.ogg` must have a length every boss track can share (simplest: one
   length for all three families). AudioManager starts a variant at the playing track's position
   (modulo its length), so different lengths drift off the bar.
   `test_music_director.gd::test_variants_share_the_length_of_their_family` fails if they differ.
3. Glitch and muffled versions are pre-rendered in the file (no live audio effect: Sample mode).
4. Re-import (open the editor, or `godot --headless --path game --import`) and check that
   `loop=true` is still set in the `.ogg.import`
   (`test_eight_music_files_load_as_looping_ogg_vorbis` fails otherwise).
5. No code change is needed. Update the Status column above and the credits.
